# Used To, Would and the Past Simple for Past Habits and States

*Lesson theme: Childhood Holidays*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Used To, Would and Be / Get Used To |
| Grammar point | Used To, Would and the Past Simple for Past Habits and States |
| Level | B1 (Intermediate) |
| Duration | 60 minutes |
| Class profile | Intermediate students who use used to accurately in all forms. They don't yet use would for past habits, or they overuse it for states (I would have a dog, We would live in Kandy) and for single events (One day we would go to Yala). They repeat used to in every sentence of a story. |
| Main aim | To clarify and practise the difference between used to (past habits and states), would (past repeated actions only, not states) and the past simple (single events, and also habits when a time period is given). |
| Subsidiary aims | To practise the contraction 'd /d/; to develop a nostalgic narrative in speaking and writing. |
| Learning outcome | By the end of the lesson, students can describe childhood memories using a natural mix of forms, e.g. We used to have a big garden. Every April, we'd go to my grandparents' village. My grandmother would wake us up at dawn. One year, we saw an elephant on the road! |
| Materials | Handout 1 (a memoir extract), Handout 2 (language focus), Handout 3 (practice), Handout 4 (memory prompts). |

## Language analysis

### Form and use

|  | **Habits (repeated actions)** | **States (be, have, live, like, know, believe)** | **Single past event** |
| :-- | :-- | :-- | :-- |
| used to | ✓ We used to swim every day. | ✓ We used to live in Kandy. | ✗ |
| would ('d) | ✓ We'd swim every day. | ✗ We would live in Kandy. | ✗ |
| past simple | ✓ We swam every day. | ✓ We lived in Kandy. | ✓ One day, we saw an elephant. |

- *would* needs a clear past context (often set up first with *used to* or a time phrase: *When I was a child, ... / Every summer, ...*).
- *would* for habits is common in storytelling and memories; it sounds nostalgic.
- Past simple must be used with a specific number or period: *I went there five times* (not *I used to go there five times*).

### Pronunciation

- *would* is usually contracted: *we'd* /wiːd/, *she'd* /ʃiːd/. The /d/ can be very light.

### Concept checking questions

*We'd swim in the river every afternoon.*

1. Did we swim many times or once? (Many times.) Is it past? (Yes.) Could I say *used to swim*? (Yes.)

*We would live in a small house.* ✗

1. Is *live* an action or a state? (A state.) So can we use *would*? (No; *used to live / lived*.)

*One morning, we saw a leopard.*

1. How many times? (Once.) So *used to* or *would*? (Neither; past simple.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| would with states (I would have a dog). | Board a list of state verbs with ✗ under would. |
| would for single events. | Timeline: repeated dots (used to / would) vs one cross (past simple). |
| Confusing past would with conditional would. | Context: past time phrase → habit. |
| Repeating used to in every sentence. | Model a paragraph: used to first, then would, then past simple for events. |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To engage students. **Interaction:** Pairs, whole class

1. Ask: *"Where did you go for school holidays when you were a child? What did you do there?"*
2. Pairs share (2 minutes). Take ideas.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present *used to*, *would* and the past simple in a memoir and clarify the differences. **Interaction:** Individual, pairs, whole class

**Part A: Reading (6 minutes)**

1. Give out Handout 1. Say: *"Read Malini's memories of holidays in her grandparents' village. What was special about them? Three minutes."*
2. Pairs compare. Students answer the questions. Check as a class.

**Part B: Finding the rules (7 minutes)**

1. Give out Handout 2. Say: *"Find the verbs with used to, would ('d) and the past simple. Complete the table and answer the questions."*
   - ICQs: *"How many forms do you look for?"* (Three.)
2. Monitor and help.

**Part C: Clarification (7 minutes)**

1. Elicit answers. Build the three-column board.
2. Ask the CCQs. Draw the timeline.
3. Board *We would live in Kandy* ✗ and *One day, we would see an elephant* ✗. Correct them.
4. Show how the memoir starts with *used to* and then switches to *would*.
5. **Pronunciation.** Drill *we'd go, she'd cook, he'd tell us stories.*

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the choice accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 3. Say: *"Exercise A: which forms are possible? Exercise B: correct the mistakes. Seven minutes."*
2. Pairs check. Check as a class.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the forms in personal narratives. **Interaction:** Individual, then groups of three, then whole class

1. Give out Handout 4. Students choose a memory prompt and make notes: two states (*used to*), three habits (*would*), one special event (past simple) (4 minutes).
2. **Tell (8 minutes).** In groups of three, students tell their memories. Listeners note one *would*, one *used to* and one past simple and ask a follow-up question.
   - ICQs: *"What do the listeners note?"* (One example of each form.)
3. **Share (6 minutes).** Each group chooses the best memory and the speaker retells it to the class.
4. Monitor and note language use.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board sentences from Stage 4 (correct and incorrect). Students correct them.
2. Quick fire: say a verb (*have, swim, see a leopard once*); students say which forms are possible.
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write a memory (150 words) about a place you used to visit as a child. Use *used to* for states, *would* for habits, and the past simple for one special event.

## Differentiation

**Support**

- Give weaker students the three-column board on a card.
- Let them use *used to* and the past simple only, adding *would* when confident.

**Stretch**

- Stronger students use *would always / would often*: *She would always save the biggest mango for me.*
- They add *used to* questions and negatives in their stories.

## Assessment and success criteria

- 8 out of 10 or better on Handout 3.
- In their stories, students do not use *would* for states or single events.
- Students use a mix of all three forms.

## Teacher's reflection

- Did the timeline help students see habits vs single events?
- Did the stories sound natural and nostalgic?

# Handout 1: Holidays in the Village

Name: ______________________________ Date: ______________

When I was a child, my grandparents used to live in a small village near Kurunegala. They had a big house with a coconut garden, and we used to spend every April holiday there.

Every morning, my grandmother would wake us up at dawn. She'd make kiribath, and we'd eat it on the veranda while the birds sang. In the afternoons, my cousins and I would swim in the tank and climb the mango trees. My grandfather used to know the name of every bird, and he'd tell us stories about the old kings.

I didn't use to like the long bus journey, but I loved the village. One year, on the way home, we saw a wild elephant on the road. The bus stopped for twenty minutes!

My grandparents don't live there any more, but I still dream about those holidays.

# Answer Key

**Handout 1**

1. Every April holiday. · 2. They would swim in the tank and climb the mango trees. · 3. They saw a wild elephant on the road; the bus stopped for twenty minutes.

**Handout 2**

| **used to** | **would / 'd** | **past simple** |
| :-- | :-- | :-- |
| used to live · used to spend · used to know · didn't use to like | would wake · 'd make · 'd eat · would swim (and climb) · 'd tell | had · saw · stopped · loved · sang |

1. No; *live* is a state verb. · 2. No; it happened once. · 3. *used to* sets the past context; then *would* is natural for repeated actions.

**Handout 3, Exercise A**

1. used to live, lived · 2. used to take, would take, took · 3. broke · 4. used to have, had · 5. used to play, would play, played · 6. went

**Handout 3, Exercise B**

**Common errors to watch for**

| **Error** | **Correction** |
| :-- | :-- |
| We would live in Kandy. | We used to live / lived in Kandy. |
| One day, we would go to Yala. | One day, we went to Yala. |
| I used to visit it five times. | I visited it five times. |
| used to ... used to ... used to ... (every sentence) | used to ... then would / past simple |
