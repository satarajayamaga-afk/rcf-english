GRAMMAR TOPIC: RELATIVE CLAUSES · C1 (Advanced) · 60 minutes

# Advanced Relative Structures (nominal relatives, relative infinitives, whereby, the extent to which)

*Lesson theme: Pioneers and Innovations*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Relative Clauses |
| Grammar point | Advanced Relative Structures (nominal relatives, relative infinitives, whereby, the extent to which) |
| Level | C1 (Advanced) |
| Duration | 60 minutes |
| Class profile | Advanced students who use all standard relative clauses accurately. In formal essays they rely on that / which / who, and they make errors with more complex structures (the thing what I need, the first woman who climb, a system which by people pay, how far that it works). |
| Main aim | To develop students' use of advanced relative structures: nominal relative clauses (what, whatever, whoever), relative infinitive clauses (the first to ..., a place to stay, someone on whom to rely), connective relatives (whereby, in which case, by which time, at which point) and the extent / degree / way to which / in which. |
| Subsidiary aims | To develop cohesion and concision in formal writing; to discuss innovation and its impact. |
| Learning outcome | By the end of the lesson, students can write a 150-word essay paragraph about an innovation using at least six advanced relative structures, e.g. What makes mobile banking revolutionary is the system whereby payments are made instantly. ## Language analysis

### Key structures

| **Structure** | **Form** | **Example** |
| :-- | :-- | :-- |
| Nominal relative | what (= the thing(s) which) + clause | What surprised me was the price. |
|  | whatever / whoever / wherever + clause | Whoever designed this was a genius. Take whatever you need. |
| Relative infinitive (after superlatives, ordinals, only, next, last) | the first / last / only + noun + to-infinitive | She was the first woman to climb Everest from Sri Lanka. |
| Relative infinitive (purpose / availability) | noun + to-infinitive; noun + preposition + whom / which + to-infinitive (formal) | a place to stay; someone on whom to rely; a reason for which to fight |
| Connective relatives | whereby (= by which); in which case; by which time; at which point | a system whereby users pay by phone; The bank may refuse, in which case ... |
| Degree / manner | the extent / degree to which; the way in which | The extent to which this helped is unclear. |

### Accuracy notes

- *what* is not used after a noun: *the thing* ***what*** *I need* ✗ → *the thing (that) I need* or *what I need*.
- After *the first / the only*, use the infinitive, not a full clause with the wrong tense: *the first person to land* (or *who landed*).
- *whereby* is formal and refers to a system, method or arrangement.

### Pronunciation

- Nominal relatives used as subjects are often followed by a pause in speech: *What surprised me | was the price.*

### Concept checking questions

*What surprised me was the price.*

1. What does *what* mean here? (The thing that.)
2. What was surprising? (The price.)

*a system whereby users pay by phone*

1. What does *whereby* mean? (By which / through which.)
2. Is it formal or informal? (Formal.)

*She was the first Sri Lankan woman to climb Everest.*

1. Did she climb Everest? (Yes.)
2. Had any Sri Lankan woman done it before? (No.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| the thing what | Board: noun + that / which; OR what alone. |
| Tense errors with the first who | Teach the first + noun + to-infinitive as a chunk. |
| whereby overused or misused for places | Rule: system / method / arrangement only. |
| Clumsy the extent to which sentences | Model: The extent to which X ... is unclear. |
| Too many structures at once | Students select four to master in their writing. |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To introduce the topic and engage students. **Interaction:** Pairs, then whole class

1. Ask: *"Which invention of the last 30 years has changed life most in your country? Why?"*
2. Pairs discuss (2 minutes). Take two or three ideas and board one sentence exactly as a student says it.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present advanced relative structures in an article and clarify their form, meaning and function. **Interaction:** Individual, groups, whole class

**Part A: Reading (5 minutes)**

1. Give out Handout 1. Say: *"Read the article. Which pioneer do you find most inspiring? Why?"*
2. Pairs compare.

**Part B: Analysis (7 minutes)**

1. Give out Handout 2. Say: *"In groups, find the structures in the article and complete the table. Then answer the questions."*
   - ICQs: *"How many structures do you find?"* (Eight.) *"Where?"* (In the article.)
2. Monitor and help.

**Part C: Clarification (8 minutes)**

1. Feedback. Build the patterns in the centre of the board.
2. **Nominal relatives.** Board *What surprised me was the price.* Ask the CCQs. Board *the thing what* ✗. Show how *what ... was* gives emphasis.
3. **Relative infinitives.** Board *the first Sri Lankan woman to climb Everest* and *someone on whom to rely.* Ask the CCQs.
4. **Connective relatives.** Board *a system whereby users pay by phone* and *The bank may refuse, in which case ...* Ask the CCQs.
5. **Degree.** Board *The extent to which mobile banking has helped farmers is remarkable.*
6. Return to the student's sentence from Stage 1 and improve it with one structure.

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the structures accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 3. Say: *"Exercise A: rewrite each sentence using the word given. Exercise B: correct the errors. Seven minutes."*
2. Pairs check. Check as a class.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the structures in a formal essay paragraph. **Interaction:** Pairs, then groups of four, then whole class

1. Give out Handout 4. Pairs choose one innovation from the notes (or their own) and write a 150-word essay paragraph evaluating its impact. They must use at least six structures from today (11 minutes).
   - ICQs: *"How many structures?"* (At least six.) *"Do you describe or evaluate?"* (Evaluate the impact.)
2. Two pairs join, read each other's paragraphs and underline the structures. They choose one sentence that could be more concise and rewrite it (4 minutes).
3. Two groups read their best sentences aloud (3 minutes).
4. Monitor and note language use.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board strong sentences and two or three with errors. Students correct the errors.
2. Ask: *"Which structure adds emphasis? Which makes writing more concise?"*
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write a 250-word essay: *Which innovation has had the greatest impact on your country?* Use at least eight advanced relative structures.

## Differentiation

**Support**

- Give weaker students a pattern card with examples.
- Provide sentence starters: *What makes ... important is ... · ... was the first ... to ... · ... is a system whereby ...*

**Stretch**

- Stronger students use *all of which, none of whom, the result of which* and *in the course of which*.
- They combine structures: *What remains unclear is the extent to which ...*

## Assessment and success criteria

- The paragraph uses at least six advanced relative structures accurately.
- No *the thing what* or incorrect *whereby* errors.
- 7 out of 8 or better on Handout 3, Exercise A.

## Teacher's reflection

- Which structures did students use most naturally?
- Did the writing become more concise and cohesive?

# Handout 1: Pioneers and Innovations

Name: ______________________________ Date: ______________

**SMALL IDEAS, BIG CHANGES**

What makes an innovation truly important is not its complexity but the extent to which it changes ordinary lives. Consider mobile money, a system whereby people send and receive payments using a basic phone. In rural areas, where banks are often hours away, it has become a lifeline. Whoever has a phone can now pay school fees, receive wages and save, which was unimaginable twenty years ago.

Another example is solar lanterns. For families with no electricity, there was often no safe way in which children could study after dark. Today, a lantern costing less than a pair of shoes gives them light to read by.

Pioneers matter too. In 2016, Jayanthi Kuru-Utumpala became the first Sri Lankan to climb Mount Everest. It was a climb on which there was no one on whom to rely but her team. She spent weeks acclimatising, by which time several climbers had already turned back.

What these stories show is that innovation is about access: giving people whatever they need to take control of their own lives. If the technology is too expensive, it will fail, in which case even the best idea changes nothing.

# Answer Key

**Handout 2**

- what + clause: *What makes an innovation truly important*; *What these stories show* · the extent to which: *the extent to which it changes ordinary lives* · whereby: *a system whereby people send and receive payments* · whoever / whatever: *Whoever has a phone*; *whatever they need* · the way in which: *no safe way in which children could study* · first + to-inf: *the first Sri Lankan to climb Mount Everest* · prep + whom + to-inf: *no one on whom to rely* · by which time / in which case: *by which time several climbers had already turned back*; *in which case even the best idea changes nothing*
   1. *The thing that makes an innovation truly important is ...*; the *what* version is more emphatic and concise. · 2. *by which / through which*; no, *where* refers to a place. · 3. *light which they can read by / by which they can read*.

**Handout 3, Exercise A**

1. What worries me is the cost. · 2. Whoever finds the keys should take them to reception. · 3. She was the first woman to win the prize. · 4. whereby students pay by phone. · 5. to which the scheme has helped farmers is not clear. · 6. in which case you must buy a new one. · 7. by which time the film had already started. · 8. on whom I can rely / on whom to rely.

**Handout 3, Exercise B**

1. The thing (that) I need is more time. / What I need is more time. · 2. He was the only player to score twice. / ... who scored twice. · 3. This is a hotel from which / where you can see the sea. · 4. Whoever told you that was wrong. · 5. The extent to which it worked is unclear.

| **Error** | **Correction** |
| :-- | :-- |
| The thing what I need ... | What I need ... / The thing (that) I need ... |
| the first woman who climb ... | the first woman to climb ... |
| a place whereby you can relax | a place where you can relax |
