GRAMMAR TOPIC: USED TO, WOULD AND BE / GET USED TO · A2 (Elementary) · 60 minutes

# Used To in Questions and Contrast with Now (Did you use to ...? not any more, still)

*Lesson theme: How Our Town Has Changed*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Used To, Would and Be / Get Used To |
| Grammar point | Used To in Questions and Contrast with Now (Did you use to ...? not any more, still) |
| Level | A2 (Elementary) |
| Duration | 60 minutes |
| Class profile | Elementary students who can make positive and negative sentences with used to. They form questions incorrectly (Used you to play?, Did you used to ...?), use used to for present habits (I use to get up at 6), and don't know how to show that something has or hasn't changed (any more, still). |
| Main aim | To clarify and practise Did ... use to ...? questions and short answers, and to contrast past and present with not ... any more / any longer and still. |
| Subsidiary aims | To clarify that there is no present form of used to (use usually + present simple); to develop speaking through an interview about how a town has changed. |
| Learning outcome | By the end of the lesson, students can ask and answer about changes, e.g. "Did there use to be a cinema here?" "Yes, there did. But it isn't there any more." "Do people still fish here?" "Yes, they still do." |
| Materials | Handout 1 (an interview with a shop owner), Handout 2 (practice), Handout 3 (old and new pictures of a town, interview cards). |

## Language analysis

### Questions and short answers

| **Question** | **Short answers** |
| :-- | :-- |
| Did you use to play cricket? | Yes, I did. / No, I didn't. |
| What did you use to eat? | I used to eat rice and curry. |
| Did there use to be a cinema here? | Yes, there did. / No, there didn't. |

- *did* shows the past, so the next word is *use* (no *d*): *Did you use to ...?*

### Contrast with now

|  | **Meaning** | **Example** |
| :-- | :-- | :-- |
| not ... any more / any longer | it was true before, not now | I don't play cricket any more. |
| still | it was true before, and it is true now | I still live in Galle. She still doesn't eat meat. |

- *still* goes before the main verb, after *be*: *He* ***still*** *works there. It's* ***still*** *open.*
- There is **no present** *used to*: for present habits, use *usually* + present simple (*I usually get up at 6*, not *I use to*).

### Pronunciation

- *Did you use to* /dɪdʒə ˈjuːstə/.
- Stress *still* and *any more* in contrasts: *I STILL live here. She doesn't work there any MORE.*

### Concept checking questions

*There used to be a cinema here, but it isn't there any more.*

1. Was there a cinema before? (Yes.) Is there one now? (No.)

*He still works at the market.*

1. Did he work there before? (Yes.) Now? (Yes.) Has anything changed? (No.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| Did you used to ...? | Board: did + use (no d), like did + play. |
| Used you to ...? | Board the question with did at the front. |
| I use to get up at 6 (present). | Board: no present used to → I usually ... |
| Position of still (He works still there). | Board: still + main verb; be + still. |

## Board plan

| **Left: questions** | **Centre: contrast** | **Right: pronunciation** |
| :-- | :-- | :-- |
| Did you use to play cricket? → Yes, I did. / No, I didn't. · What did you use to eat? · Did there use to be a cinema? → Yes, there did. · not: Did you used to ✗ · not: Used you to ✗ | THEN ✓ NOW ✗ → not ... any more · THEN ✓ NOW ✓ → still · He still works there. · It's still open. · I don't play any more. · present habit: I usually get up at 6 (not: I use to ✗) | Did you use to /dɪdʒə ˈjuːstə/ · I STILL live here · not any MORE |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To engage students with the topic. **Interaction:** Pairs, whole class

1. Ask: *"How was our town different 20 years ago? Ask your parents' generation."*
2. Pairs brainstorm (2 minutes). Take ideas: *"There were no supermarkets ..."*

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present questions with *used to*, *still* and *any more* in context and clarify the form. **Interaction:** Individual, pairs, whole class

**Part A: Reading (6 minutes)**

1. Give out Handout 1. Say: *"Read the interview with Mr Fernando, who has had a shop in Negombo for 40 years. What has changed? What hasn't? Three minutes."*
2. Pairs compare. Students answer the questions. Check as a class.

**Part B: Noticing (4 minutes)**

1. Say: *"Find the questions. What word starts them? Find still and any more."* Pairs compare.

**Part C: Clarification (10 minutes)**

1. Board *Did you use to sell fish?* and the short answers. Cross out *Did you used to* and *Used you to*.
2. Board *There used to be a cinema* and *Did there use to be ...?*
3. Draw the then / now ticks for *any more* and *still*. Ask the CCQs.
4. Board *I use to get up at 6* ✗ → *I usually get up at 6*.
5. **Pronunciation.** Drill *Did you use to ...?* /dɪdʒə ˈjuːstə/ and stress on *still*.

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the forms accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 2. Say: *"Exercise A: write questions with used to. Exercise B: still or any more? Exercise C: correct the mistakes. Seven minutes."*
2. Pairs check. Check as a class.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the language in an interview. **Interaction:** Pairs, then whole class

1. **Then and now pictures (7 minutes).** Give out Handout 3. Pairs compare the two pictures of "Lakeside" 30 years ago and today: *"There used to be a cinema, but it isn't there any more. The temple is still there."*
2. **Interview (8 minutes).** Student A is a reporter; Student B is an older resident (role card). A interviews B: *"Did you use to swim in the lake?" "Yes, I did, but I don't any more. It's too dirty."* Swap with the second card.
   - ICQs: *"What does the reporter ask about?"* (How the town has changed.)
3. Two pairs perform (3 minutes).
4. Monitor and note errors.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board four sentences from your notes (two with errors). Students correct them.
2. Ask: *"Is there a present form of used to?"* (No.)
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Interview an older family member about how your town or village has changed. Write 5 questions with *Did ... use to ...?* and their answers, using *still* and *any more*.

## Differentiation

**Support**

- Give weaker students the question frame *Did you use to ...?* on a card.
- In the picture task, give them a list of places.

**Stretch**

- Stronger students use *no longer*: *The cinema no longer exists.*
- They use *There used to be* + plural: *There used to be lots of fishing boats.*

## Assessment and success criteria

- 10 out of 12 or better on Handout 2.
- In the interview, students form *Did ... use to ...?* questions correctly.
- Students use *still* and *any more* correctly.

## Teacher's reflection

- Did the then / now ticks make *still* and *any more* clear?
- Was the interview realistic and engaging?

# Handout 1: Forty Years in Negombo

Name: ______________________________ Date: ______________

**Reporter:** Mr Fernando, you've had this shop for 40 years. What did you use to sell? **Mr Fernando:** I used to sell fishing nets and ropes. Most people here used to be fishermen. **Reporter:** Do you still sell nets? **Mr Fernando:** A few, but not many. Now I sell phone cards and snacks to tourists! **Reporter:** Did there use to be many tourists? **Mr Fernando:** No, there didn't. There used to be only a few small guest houses. Now there are big hotels on the beach. **Reporter:** Did you use to live above the shop? **Mr Fernando:** Yes, I did. My family doesn't live here any more. We moved to a house near the lagoon. But I still open the shop at 6 every morning!

**Answer the questions.**

1. What did Mr Fernando use to sell? ______________________________
2. Does he still sell nets? ______________________________
3. Did there use to be big hotels? ______________________________
4. What does he still do every morning? ______________________________

# Handout 3: Lakeside, Then and Now

**Lakeside 30 years ago**

- a small cinema · a big lake with clean water · many fishing boats · a train station · a market every Sunday · a temple · no supermarket · no traffic lights

**Lakeside today**

- no cinema (a shopping mall) · a small, dirty lake · two fishing boats · the train station (still there) · no Sunday market · the same temple · two supermarkets · lots of traffic

**Common errors to watch for**

| **Error** | **Correction** |
| :-- | :-- |
| Did you used to ...? | Did you use to ...? |
| Used you to ...? | Did you use to ...? |
| I use to get up early. (present) | I usually get up early. |
| He works still there. | He still works there. |
