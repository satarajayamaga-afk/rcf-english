# Advanced Linkers and Cohesion in Academic Writing (whereas, albeit, notwithstanding, provided that, given that, this + noun)

*Lesson theme: The Future of Remote Work*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Linking Words |
| Grammar point | Advanced Linkers and Cohesion in Academic Writing (whereas, albeit, notwithstanding, provided that, given that, this + noun) |
| Level | C1 (Advanced) |
| Duration | 60 minutes |
| Class profile | Advanced students who use common linkers accurately but overuse however, moreover and on the other hand, often mechanically at the start of every sentence. They rarely use subordinating linkers for comparison and condition (whereas, provided that, given that), misuse albeit with a full clause, and repeat nouns instead of using cohesive this / such + noun. |
| Main aim | To develop students' accurate use of advanced linkers for contrast and comparison (whereas, while, albeit, notwithstanding), condition (provided / providing that, as long as, in the event that, unless) and reason / premise (given that, in view of, insofar as), together with cohesive referencing (this trend, such an approach, the former / the latter). |
| Subsidiary aims | To reduce mechanical overuse of sentence-initial linkers; to edit a paragraph for cohesion. |
| Learning outcome | By the end of the lesson, students can write and edit a cohesive academic paragraph, e.g. Whereas office work offers structure, remote work offers flexibility, albeit at the cost of social contact. Provided that employees have reliable internet, productivity need not suffer. Given that housing costs are rising, this flexibility is increasingly valuable. |
| Materials | Handout 1 (two versions of a paragraph), Handout 2 (language analysis), Handout 3 (practice), Handout 4 (editing task). |

## Language analysis

### Contrast and comparison

| **Linker** | **Grammar** | **Example** |
| :-- | :-- | :-- |
| whereas / while | + clause; compares two facts | Whereas managers favour the office, most employees prefer hybrid work. |
| albeit | + adjective, adverb or noun phrase (not a full clause) | a significant, albeit temporary, increase · Productivity rose, albeit slowly. |
| notwithstanding | + noun (before or after) | Notwithstanding these concerns, the policy was adopted. / these concerns notwithstanding |

### Condition

| **Linker** | **Grammar** | **Example** |
| :-- | :-- | :-- |
| provided (that) / providing (that) / as long as | + clause (present tense for future) | Provided that staff have good internet, they can work from home. |
| in the event that | + clause (formal) | In the event that the system fails, data is backed up. |
| unless | + clause = if ... not | Unless support is provided, isolation will increase. |

### Premise and extent

| **Linker** | **Grammar** | **Example** |
| :-- | :-- | :-- |
| given that / in view of the fact that | + clause | Given that commuting takes two hours, remote work saves time. |
| given / in view of | + noun | Given the costs, many firms have reduced office space. |
| insofar as | + clause = "to the extent that" | Remote work is beneficial insofar as it reduces commuting. |

### Cohesive referencing

- *this / these / such* + summarising noun: *... rents have risen sharply.* ***This trend*** *...* · *... such an approach ...*
- *the former / the latter* for two items mentioned.
- Use linkers sparingly: good cohesion comes from referencing and logical order, not a linker in every sentence.

### Concept checking questions

*Productivity rose, albeit slowly.*

1. Did productivity rise? (Yes.) Quickly? (No.) Can I write *albeit it rose slowly*? (No; *albeit* + phrase, not a clause.)

*Provided that staff have good internet, they can work from home.*

1. Can staff without good internet work from home? (No; it's a condition.)

*Whereas managers favour the office, employees prefer hybrid work.*

1. Is this a contrast between two groups? (Yes.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| albeit + clause. | Board: albeit + adjective / adverb / noun phrase. |
| whereas used like however at the start of a new sentence. | Show it joins two clauses in one sentence. |
| provided that + will. | Board: present tense after conditional linkers. |
| Mechanical linker at every sentence start. | Edit task: remove half the linkers and add referencing nouns. |
| Repetition of nouns (remote work ... remote work ... remote work). | Teach this approach, such arrangements, the former. |

## Board plan

| **Left: contrast / comparison** | **Centre: condition / premise** | **Right: cohesion** |
| :-- | :-- | :-- |
| whereas / while + clause · albeit + adjective / adverb / noun phrase · notwithstanding + noun · not: albeit it was slow ✗ · not: Whereas, ... ✗ (new sentence) | provided (that) / providing / as long as + present · in the event that · unless = if not · given that + clause · given + noun · insofar as = to the extent that · not: provided that it will ✗ | this trend · these findings · such an approach · the former / the latter · fewer linkers, more referencing · logical order |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To engage students and raise awareness of cohesion. **Interaction:** Pairs, whole class

1. Ask: *"Would you prefer to work from home, in an office, or both? Why?"*
2. Pairs discuss (2 minutes). Take ideas.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present advanced linkers and referencing by comparing two paragraphs and clarify their grammar. **Interaction:** Individual, groups, whole class

**Part A: Reading (6 minutes)**

1. Give out Handout 1. Say: *"Read Version A and Version B of the same paragraph. Which reads better? Why?"*
2. Pairs discuss. Elicit: Version A overuses *However / Moreover* and repeats nouns; Version B uses varied linkers and referencing.

**Part B: Analysis (6 minutes)**

1. Give out Handout 2. Say: *"In groups, find the linkers in Version B and classify them. Then find three examples of referencing."*
   - ICQs: *"Which version do you analyse?"* (B.)
2. Monitor and help.

**Part C: Clarification (8 minutes)**

1. Feedback. Build the board.
2. Focus on *albeit* and *whereas*. Ask the CCQs.
3. Highlight present tense after *provided that*.
4. Show how *This trend* and *such arrangements* summarise earlier ideas.
5. Discuss: *"Why does Version B have fewer sentence-initial linkers but feel more connected?"*

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the linkers and referencing accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 3. Say: *"Exercise A: choose the correct linker. Exercise B: correct the errors. Exercise C: replace the repeated words with referencing. Seven minutes."*
2. Pairs check. Check as a class.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To edit and write cohesive academic text. **Interaction:** Pairs, then individual, then whole class

1. **Edit (8 minutes).** Give out Handout 4. Pairs edit a mechanically linked paragraph about online learning: remove unnecessary linkers, add at least four advanced linkers, and replace repetition with referencing.
   - ICQs: *"Do you add or remove linkers?"* (Both: remove weak ones, add better ones.)
2. **Write (7 minutes).** Students write a short paragraph (100–120 words) on *"Should employers allow a four-day week?"* using at least four linkers from today and two referencing phrases.
3. Two students read their paragraphs aloud (3 minutes).
4. Monitor and note language use.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board sentences from Stage 4 (effective and incorrect). Students improve them.
2. Ask: *"What makes a paragraph cohesive besides linking words?"*
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write an academic essay paragraph (250 words) discussing the advantages and disadvantages of remote work. Use at least six linkers from today, including *albeit* and *whereas*, and three referencing phrases. Highlight them.

## Differentiation

**Support**

- Give weaker students the grammar tables during editing and writing.
- Limit them to *whereas, provided that, given that* and *this + noun*.

**Stretch**

- Stronger students use *inasmuch as, lest, be that as it may, on the grounds that*.
- They analyse a real academic abstract for cohesive devices.

## Assessment and success criteria

- The edited paragraph removes mechanical linkers and adds at least four advanced linkers correctly.
- *albeit* is followed by a phrase, *provided that* by a present tense, *whereas* by a clause.
- At least two referencing phrases replace repetition.
- 10 out of 12 or better on Handout 3.

## Teacher's reflection

- Did students see that fewer linkers can mean better cohesion?
- Was *albeit* used correctly in the freer writing?

# Handout 1: Two Versions of a Paragraph

Name: ______________________________ Date: ______________

**Version A**

Remote work has become popular. However, remote work has some problems. Moreover, remote work can make people feel lonely. On the other hand, remote work saves time because people don't commute. However, managers think remote work reduces productivity. Moreover, employees need good internet for remote work. In conclusion, remote work has advantages and disadvantages.

**Version B**

Remote work has expanded rapidly since 2020. Whereas many managers remain sceptical, most employees report that such arrangements improve their work–life balance, albeit at the cost of some social contact. Given that commuting in large cities can take two hours a day, this benefit is considerable. Provided that staff have reliable internet and clear objectives, productivity need not suffer. Notwithstanding these advantages, isolation remains a genuine concern; unless organisations provide regular opportunities for face-to-face contact, this problem is likely to grow.

# Answer Key

**Handout 1**

1. Version B: varied linkers, logical connections, less repetition. · 2. Version A: seven times; Version B: once.

**Handout 2, Exercise A**

- Contrast / comparison: whereas, albeit, notwithstanding · Condition: provided that, unless · Premise: given that

**Handout 2, Exercise B**

- *such arrangements* → remote work · *this benefit* → saving commuting time / better work–life balance · *these advantages* → work–life balance and maintained productivity · (also *this problem* → isolation)

**Handout 2, Exercise C**

1. A phrase (*at the cost of some social contact*). · 2. Present simple (*have*).

**Handout 3, Exercise A**

1. Whereas · 2. albeit · 3. Given · 4. as long as · 5. Notwithstanding · 6. Unless

**Handout 3, Exercise B**

1. Sales increased, albeit slowly. · 2. Provided that the weather is good, we'll go. · 3. Whereas rural areas are poor, cities are wealthy. / Rural areas are poor, whereas cities are wealthy.

**Handout 3, Exercise C**

1. *This increase / This trend* has forced ... · 2. *Such companies / These companies* report ... · 3. *The latter* were faster, but *the former* were cheaper.

**Handout 4 (model)**

Online learning is growing rapidly, albeit unevenly. Provided that students have a reliable internet connection, it offers considerable flexibility. Whereas some learners thrive in this environment, others struggle with motivation. Given that many teachers have had little training in digital methods, this problem is not surprising. Notwithstanding these challenges, such courses are likely to remain an important part of education.

**Common errors to watch for**

| **Error** | **Correction** |
| :-- | :-- |
| albeit it was slow | albeit slowly / albeit slow |
| Whereas, cities are wealthy. | Whereas rural areas are poor, cities are wealthy. |
| Provided that it will rain, ... | Provided that it rains, ... |
| However, ... Moreover, ... However, ... (every sentence) | Fewer linkers; use referencing (this trend, such an approach) |
