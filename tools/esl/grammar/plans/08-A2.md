GRAMMAR TOPIC: CONDITIONALS · A2 (Elementary) · 60 minutes

# First Conditional (If + present, will)

*Lesson theme: Planning the Class Trip*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Conditionals |
| Grammar point | First Conditional (If + present, will) |
| Level | A2 (Elementary) |
| Duration | 60 minutes |
| Class profile | Elementary students who know the zero conditional and will for predictions. They put will in both clauses (If it will rain, we will stay home) and confuse the first conditional with the zero conditional. |
| Main aim | To present and practise the first conditional (If + present simple, will / won't + base verb) for real possibilities in the future. |
| Subsidiary aims | To practise might for less certain results; to develop fluency in a planning discussion; to practise contracted 'll and won't. |
| Learning outcome | By the end of the lesson, students can discuss a plan and its possible problems, e.g. If it rains, we'll go to the museum. If we leave late, we might miss the train. |
| Materials | Handout 1 (class WhatsApp chat), Handout 2 (practice), Handout 3 (chain story cards), Handout 4 (trip planning sheet). |

## Language analysis

### Form

| **If clause** | **Main clause** |
| :-- | :-- |
| If + present simple | will / won't + base verb |
| If it rains, | we'll go to the museum. |
| If we leave at 6, | we won't get stuck in traffic. |
| If you forget your hat, | you'll get sunburnt. |

- Question: *What will we do if it rains?*
- *might* for a less certain result: *If we're late, we* ***might*** *miss the train.*
- The clauses can change places: *We'll go to the museum if it rains.*

### Meaning and use

- A **real** possibility in the future: it is possible and quite likely.
- Compare: zero conditional = always true (*If it rains, the roads get wet*); first conditional = one future situation (*If it rains on Saturday, we'll stay inside*).

### Pronunciation

- Contracted *'ll*: *we'll* /wiːl/, *you'll* /juːl/, *it'll* /ˈɪtl/. *won't* /wəʊnt/.
- Intonation: rise at the end of the *if* clause, fall at the end: *If it rains ↗, we'll go to the museum ↘.*

### Concept checking questions

*If it rains on Saturday, we'll go to the museum.*

1. Do we know if it will rain? (No.)
2. Is it possible? (Yes.)
3. Is it about the past, now or the future? (The future, Saturday.)
4. What's the plan if it rains? (The museum.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| will in the if clause (If it will rain). | Board the rule with will crossed out in the if clause. |
| Missing will in the main clause (If it rains, we go). | Contrast with the zero conditional: one future day vs always. |
| Not hearing 'll. | Drill contracted forms; minimal pairs We go / We'll go. |
| won't pronounced like want. | Drill I won't /wəʊnt/ vs I want /wɒnt/. |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To introduce the context and generate interest. **Interaction:** Whole class, pairs

1. Say: *"Our class is going on a trip to Nuwara Eliya on Saturday!"* Ask: *"What can go wrong?"* Pairs list three problems (2 minutes).
2. Take ideas and board key words: *rain, late, traffic, sick, forget*.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present the first conditional in context and clarify meaning, form and pronunciation. **Interaction:** Individual, pairs, whole class

**Part A: Reading (6 minutes)**

1. Give out Handout 1. Say: *"Read the class chat. What will the class do if it rains? Three minutes."*
   - ICQs: *"Do you read the whole chat?"* (Yes.)
2. Pairs check. Students answer the four questions. Check as a class.

**Part B: Noticing (4 minutes)**

1. Say: *"Underline every sentence with if. Circle the verbs."* Pairs compare.
2. Ask: *"Which tense comes after if? What comes in the other part?"*

**Part C: Clarification (10 minutes)**

1. **Meaning.** Board *If it rains on Saturday, we'll go to the museum.* Ask the CCQs. Draw a timeline: NOW → Saturday with a question mark over a rain cloud.
2. **Form.** Elicit *If + present simple, will / won't + base verb*. Cross out *will* in *If it will rain*.
3. **might.** Board *If we leave late, we might miss the train.* Ask: *"Are we sure we'll miss it?"* (No, maybe.)
4. **Zero vs first.** Board *If it rains, the roads get wet* (always) and *If it rains on Saturday, we'll stay inside* (one future situation).
5. **Pronunciation.** Drill contractions and intonation: *If it rains ↗, we'll go to the museum ↘. If you're late ↗, you'll miss the bus ↘.*

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the form accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 2. Say: *"Exercise A: complete the sentences. Exercise B: match and write. Seven minutes."*
2. Pairs check. Check as a class; ask students to say the sentences with contractions.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the first conditional fluently in a game and a planning task. **Interaction:** Groups, then whole class

1. **Chain story (6 minutes).** Give each group a starter card from Handout 3. Student 1 reads it (*If I don't go to school tomorrow, ...*) and finishes it (*I'll stay in bed*). Student 2 uses the result to start a new sentence (*If I stay in bed, I'll watch TV*). Continue around the group as long as possible.
   - ICQs: *"Where does your sentence start?"* (With the end of the last sentence.)
2. **Plan the trip (10 minutes).** Give out Handout 4. Groups choose a destination and plan the day. For each problem on the sheet, they write a solution with *If ..., we'll ...* Then they present their plan to the class (1 minute each).
3. The class votes for the best-prepared group.
4. Monitor and note errors.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board four sentences heard in Stage 4 (two with errors). Students correct them.
2. Quick round: each student finishes *If I have time this weekend, ...*
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write a message (80 words) to a friend about your plans for the weekend. Include at least four first conditional sentences, one with *might*.

## Differentiation

**Support**

- Give weaker students a list of base verbs for the chain story.
- Provide the frame *If ..., we'll ...* on the planning sheet.

**Stretch**

- Stronger students use *unless* and *as soon as* (preview): *We'll leave as soon as the bus arrives.*
- They add a second result: *If it rains, we'll go to the museum and then we'll have tea.*

## Assessment and success criteria

- 8 out of 10 or better on Handout 2, Exercise A.
- In the planning task, students use the present simple after *if* and *will* in the main clause.
- Students use contracted *'ll* in speech.

## Teacher's reflection

- How many students still used *will* after *if*?
- Did the chain story keep going? Was it fun?

**Handout 2, Exercise B**

1 c · 2 a · 3 b · 4 d

1. If you eat all the cake, you'll feel sick. · 2. If you don't take an umbrella, you'll get wet. · 3. If you can't find your pen, I'll lend you mine. · 4. If we win the match, we'll have a party.

**Common errors to watch for**

| **Error** | **Correction** |
| :-- | :-- |
| If it will rain, we will stay home. | If it rains, we'll stay home. |
| If you are late, the bus doesn't wait. (one future day) | If you're late, the bus won't wait. |
| I want go if I have time. (meaning I'll) | I'll go if I have time. |
| If she will come, I am happy. | If she comes, I'll be happy. |
