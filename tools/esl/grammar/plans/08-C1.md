GRAMMAR TOPIC: CONDITIONALS · C1 (Advanced) · 60 minutes

# Inverted and Alternative Conditionals (Had I known, Should you, Were it not for, provided that)

*Lesson theme: Writing a Formal Proposal*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Conditionals |
| Grammar point | Inverted and Alternative Conditionals (Had I known, Should you, Were it not for, provided that) |
| Level | C1 (Advanced) |
| Duration | 60 minutes |
| Class profile | Advanced students who use all the main conditional types accurately but rely on if in every sentence. Their formal writing sounds repetitive, and they make errors with inversion (Had I knew, Should you will need) and with unless (unless you don't pay). |
| Main aim | To develop students' use of inverted conditionals (Had ..., Should ..., Were ... to), conditional linkers (provided / providing that, as long as, on condition that, unless, supposing, otherwise) and but for / were it not for / if it hadn't been for in formal writing and speech. |
| Subsidiary aims | To develop awareness of register; to write a formal proposal collaboratively and present it persuasively. |
| Learning outcome | By the end of the lesson, students can write and present a 150-word formal proposal using at least six inverted or alternative conditional structures accurately. |
| Materials | Handout 1 (informal and formal versions), Handout 2 (model proposal for analysis), Handout 3 (practice), Handout 4 (proposal brief and planning sheet). |

## Language analysis

### Inverted conditionals (formal; *if* is omitted)

| **Type** | **Inverted form** | **Equivalent with if** |
| :-- | :-- | :-- |
| First (formal, less likely) | Should + subject + base verb | If you (should) require assistance, ... → Should you require assistance, please contact us. |
| Second | Were + subject + to + infinitive / Were + subject + complement | If the council approved ... → Were the council to approve the plan, ... · Were I in your position, ... |
| Third | Had + subject + past participle | If we had known ... → Had we known about the problem, we would have acted sooner. |
| Negative | No contraction: Had we not ..., Were it not ..., Should you not ... | not Hadn't we known |

### Alternative conditional expressions

| **Expression** | **Meaning** | **Example** |
| :-- | :-- | :-- |
| provided / providing (that), as long as, on condition that | only if (a condition must be met) | The project will succeed provided that funding is secured. |
| unless | if ... not / except if | Unless action is taken, the problem will worsen. (not unless action isn't taken) |
| supposing / suppose / what if | imagine that | Supposing the plan failed, what would we do? |
| otherwise | if not (refers back) | We must act now; otherwise, costs will rise. |
| but for + noun / were it not for + noun / if it hadn't been for + noun | without (this thing) | But for the volunteers, the event would have failed. Were it not for the grant, the library would close. |
| in case | as a precaution (not a condition) | Bring an umbrella in case it rains. |

### Pronunciation

- Inverted auxiliaries are stressed at the start of a sentence: *HAD we known ..., SHOULD you require ...*
- A slight pause after the conditional clause in formal speech.

### Concept checking questions

*Had we known about the flooding, we would have postponed the event.*

1. Did we know about the flooding? (No.)
2. Did we postpone the event? (No.)
3. Is this formal or informal? (Formal.)

*The library will stay open provided that the council renews the grant.*

1. Will the library stay open if the council doesn't renew the grant? (No.)
2. Does *provided that* mean *only if* or *even if*? (Only if.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| Wrong verb form after inversion (Had I knew, Should you will need). | Board the patterns: Had + subject + past participle; Should + subject + base verb. |
| Contracted negatives (Hadn't we known). | Show Had we not known; explain that inverted negatives are not contracted. |
| Double negative with unless (unless you don't pay). | Board unless = if ... not; transformation drill. |
| Confusing in case with if. | Contrast: I'll take an umbrella in case it rains (precaution) vs I'll take an umbrella if it rains (only when it rains). |
| Over-use making texts heavy. | Discuss balance; one or two inversions per paragraph is enough. |

## Board plan

| **Left: register** | **Centre: patterns** | **Right: meaning** |
| :-- | :-- | :-- |
| FORMAL: proposals, reports, official letters, speeches · INFORMAL: conversation, messages (use if) | Should + S + verb · Were + S + to + verb · Were + S + complement · Had + S + pp · Had S not + pp (no contraction) · provided (that) / as long as / on condition that + present · unless + positive verb · But for / Were it not for + noun | Should = less likely future · Were ... to = imaginary future · Had = imaginary past · provided that = only if · unless = if not · but for = without · in case = precaution |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To raise awareness of formal conditional structures. **Interaction:** Pairs, then whole class

1. Give out Handout 1. Pairs match the five informal sentences with their formal versions (3 minutes).
2. Check. Ask: *"Which word is missing from the formal versions?"* (*if*.) *"What has happened to the word order?"* Accept ideas; don't explain yet.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present inverted and alternative conditionals in a model text and clarify their form, meaning and register. **Interaction:** Groups, whole class

**Part A: Reading (5 minutes)**

1. Give out Handout 2. Say: *"Read the proposal. What does the student council want? What conditions does it offer?"*
2. Pairs compare answers.

**Part B: Analysis (7 minutes)**

1. Say: *"In groups, find every conditional structure in the proposal. Rewrite each one with if. Then answer the analysis questions."*
   - ICQs: *"Do you rewrite with if or without if?"* (With *if*.) *"How many questions?"* (Five.)
2. Monitor and help.

**Part C: Clarification (8 minutes)**

1. Feedback. Build the patterns in the centre of the board.
2. **Inversion.** Show the three patterns side by side with their *if* equivalents: *Should you require → If you require; Were the council to approve → If the council approved; Had we known → If we had known.* Ask the CCQs.
3. **Negatives.** Board *Hadn't we known* ✗ → *Had we not known* ✓.
4. **Linkers.** Elicit the meaning of *provided that, unless, otherwise, but for*. Board *unless you don't pay* ✗ and ask what's wrong.
5. **in case.** Contrast *in case* (precaution) with *if* (condition).
6. **Pronunciation.** Drill with stress on the inverted auxiliary: *HAD we known, we would have acted sooner. SHOULD you require further information, please contact us.*

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise the structures accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 3. Say: *"Exercise A: rewrite each sentence using the word in brackets. Six minutes."*
2. Pairs check. Feedback as a class, focusing on word order and verb forms.
3. **Exercise B:** pairs correct the five errors. Check quickly.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the structures accurately in a formal written proposal and a persuasive presentation. **Interaction:** Groups of three, then whole class

1. Give out Handout 4. Say: *"You are a group of residents. Write a formal proposal (about 150 words) to the city council for one of the projects. Use at least six structures from today."*
   - ICQs: *"Who is the proposal for?"* (The city council.) *"How many structures?"* (At least six.)
2. Groups choose a project, plan (3 minutes) and write (8 minutes).
3. Each group presents its proposal in one minute. The "council" (the rest of the class) asks one question each, using a conditional: *"Supposing the funding were cut, what would you do?"* (5 minutes.)
4. The class votes for the most convincing proposal (2 minutes).
5. Monitor and note language use.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board the most effective sentences and two or three with errors. Students correct the errors.
2. Ask: *"Would you use Had I known in a text message to a friend?"* (No, *If I'd known*.) Discuss register.
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write a formal letter (220 words) to a company or official body requesting a change. Use at least three inverted conditionals and three alternative conditional expressions.

## Differentiation

**Support**

- Give weaker students a pattern card with each structure and its *if* equivalent.
- Provide a proposal template with headings: *Purpose · Proposal · Conditions · Benefits · Risks.*

**Stretch**

- Stronger students use mixed inverted forms: *Had the council invested earlier, the park would be open today.*
- They use *If it weren't for ... / If it hadn't been for ...* and *Were it not for ...* in the same text and explain the difference in time reference.

## Assessment and success criteria

- The proposal uses at least six inverted or alternative conditional structures accurately.
- No contracted negatives in inversion and no double negatives with *unless*.
- 7 out of 8 or better on Handout 3, Exercise A.

## Teacher's reflection

- Did students understand the time reference of *Should, Were* and *Had*?
- Was the register appropriate, or did texts become too heavy?

# Handout 2: Model Proposal

**PROPOSAL: A STUDY CENTRE FOR THE PUBLIC LIBRARY**

**To:** The Library Committee **From:** The Student Council

**Background:** Each year, hundreds of students use the library to prepare for their exams. Were it not for the library, many students would have nowhere quiet to study. However, the building closes at 5 pm. Had the opening hours been extended last year, more students would have passed their A-level examinations.

**Proposal:** We propose converting the unused ground-floor room into a study centre that is open until 9 pm on weekdays.

**Conditions:** The student council will provide volunteers to supervise the centre, provided that the library provides basic furniture and Wi-Fi. Students will be allowed to use the centre only as long as they register in advance.

**Risks:** Unless additional cleaning is arranged, the room may become untidy. We therefore suggest a small monthly fee of Rs. 200; otherwise, the costs may be too high for the library. Supposing the number of users were lower than expected, the centre could open three evenings a week instead.

**Conclusion:** Were the committee to approve this proposal, the centre could open in January. Should you require any further information, please contact the student council secretary.

# Answer Key

**Handout 1**

1 c · 2 a · 3 b · 4 e · 5 d

*if* is omitted and the auxiliary (*should, had, were*) comes before the subject.

**Handout 2**

1. *Had the opening hours been extended* → If the opening hours had been extended; *Were the committee to approve* → If the committee approved; *Should you require* → If you require (also *Were it not for the library* → If it weren't for the library)
2. *Had the opening hours been extended last year ...*
3. *provided that*, *as long as*
4. If additional cleaning is not arranged, the room may become untidy.
5. The suggestion of a monthly fee: if there is no fee, the costs may be too high.

**Common errors to watch for**

| **Error** | **Correction** |
| :-- | :-- |
| Had I knew, I would have come. | Had I known, I would have come. |
| Hadn't we left, ... | Had we not left, ... |
| Unless you don't study, you'll fail. | Unless you study, you'll fail. |
| Should you will need help, ... | Should you need help, ... |
| I'll take a coat if it gets cold. (meaning as a precaution) | I'll take a coat in case it gets cold. |
