GRAMMAR TOPIC: USED TO, WOULD AND BE / GET USED TO · B2 (Upper-intermediate) · 60 minutes

# Used To vs Be Used To vs Get Used To (I used to drive / I'm used to driving / I'm getting used to driving)

*Lesson theme: Moving Abroad*

## Lesson overview

|  |  |
| :-- | :-- |
| Grammar topic | Used To, Would and Be / Get Used To |
| Grammar point | Used To vs Be Used To vs Get Used To (I used to drive / I'm used to driving / I'm getting used to driving) |
| Level | B2 (Upper-intermediate) |
| Duration | 60 minutes |
| Class profile | Upper-intermediate students who use used to and would accurately for past habits. They confuse used to + infinitive with be / get used to + -ing (I'm used to drive on the left, I used to living alone), and don't use get used to to talk about the process of adapting. |
| Main aim | To clarify and practise the form and meaning of used to + infinitive (past habit), be used to + noun / -ing (familiar, not strange) and get used to + noun / -ing (the process of becoming familiar), in a range of tenses. |
| Subsidiary aims | To practise get used to in different tenses (I'm getting / I got / I'll get / I've got used to); to develop speaking about adapting to change. |
| Learning outcome | By the end of the lesson, students can describe adapting to a new situation, e.g. In Sri Lanka I used to eat rice every day. In Canada, I'm not used to the cold. I'm slowly getting used to it, and I'll soon get used to cooking for myself. |
| Materials | Handout 1 (a blog post), Handout 2 (language analysis), Handout 3 (practice), Handout 4 (role cards and situations). |

## Language analysis

### Form and meaning

| **Structure** | **Meaning** | **Form** | **Example** |
| :-- | :-- | :-- | :-- |
| used to | past habit or state, not now | used to + infinitive | I used to drive on the left. |
| be used to | it's familiar / normal for me; not strange | be (any tense) + used to + noun / pronoun / -ing | I'm used to driving on the left. She isn't used to the cold. |
| get used to | the process of becoming familiar | get (any tense) + used to + noun / pronoun / -ing | I'm getting used to driving on the right. You'll get used to it. |

- In *be / get used to*, *to* is a **preposition**, so it is followed by a noun or -ing (like *look forward to*).
- *be used to* and *get used to* can be in any tense: *I was used to ..., I've got used to ..., I'll never get used to ...*
- *used to* (past habit) only exists in the past.

### Pronunciation

- All three use /ˈjuːstə/ (before consonants) or /ˈjuːstu/ (before vowels): *I'm used to it* /aɪm ˈjuːstu ɪt/.

### Concept checking questions

*I'm used to working at night.*

1. Is working at night strange for me? (No, it's normal.) Is it past or present? (Present.)

*I'm getting used to the food.*

1. Was the food strange at first? (Yes.) Is it still a bit strange? (A bit, but it's becoming normal.)

*I used to work at night.*

1. Do I work at night now? (No.)

## Anticipated problems and solutions

| **Problem** | **Solution** |
| :-- | :-- |
| be used to + infinitive (I'm used to drive). | Board: to = preposition → noun / -ing (compare look forward to). |
| I used to living alone (meaning be used to). | Ask: past habit or familiar now? Add am. |
| Missing be (I used to the weather). | Board: be / get + used to + noun. |
| Not using get used to for change. | Timeline: strange → getting used to → used to. |
| Tense of get (I got used to vs I'm getting used to). | Practise with the timeline at different points. |

## Board plan

| **Left: used to** | **Centre: be used to** | **Right: get used to** |
| :-- | :-- | :-- |
| past habit / state, not now · used to + infinitive · I used to drive on the left. · I didn't use to cook. | familiar, not strange · be + used to + noun / -ing · I'm used to driving on the left. · She isn't used to the cold. · not: I'm used to drive ✗ | becoming familiar (process) · get + used to + noun / -ing · I'm getting used to it. · I got used to it quickly. · You'll get used to it. · strange → getting used to → used to |

## Procedure

### Stage 1: Warm-up (5 minutes)

**Stage aim:** To engage students with the topic. **Interaction:** Pairs, whole class

1. Ask: *"Imagine you move to another country. What would be the most difficult thing to get used to?"*
2. Pairs list three things (2 minutes). Take ideas.

### Stage 2: Presentation (20 minutes)

**Stage aim:** To present the three structures in context and clarify their form and meaning. **Interaction:** Individual, groups, whole class

**Part A: Reading (6 minutes)**

1. Give out Handout 1. Say: *"Read Dilshan's blog about moving from Colombo to Toronto. What does he find difficult? What is he getting used to? Three minutes."*
2. Pairs compare. Students answer the questions. Check as a class.

**Part B: Analysis (6 minutes)**

1. Give out Handout 2. Say: *"In groups, find the sentences with used to. Put them in the three columns. What comes after each one?"*
   - ICQs: *"How many columns?"* (Three.)
2. Monitor and help.

**Part C: Clarification (8 minutes)**

1. Feedback. Build the board.
2. Ask the CCQs. Draw the timeline: strange → getting used to → used to.
3. Explain *to* as a preposition. Compare *I'm looking forward to seeing you*.
4. Show *get used to* in different tenses.
5. **Pronunciation.** Drill *I'm used to it. I'm getting used to it. I used to love it.*

### Stage 3: Controlled practice (10 minutes)

**Stage aim:** To practise form and meaning accurately. **Interaction:** Individual, then pairs, then whole class

1. Give out Handout 3. Say: *"Exercise A: choose the correct form. Exercise B: complete with the correct form of be used to or get used to. Exercise C: correct the mistakes. Seven minutes."*
2. Pairs check. Check as a class.

### Stage 4: Freer practice (18 minutes)

**Stage aim:** To use the structures fluently to talk about change. **Interaction:** Pairs, then groups, then whole class

1. **Role-play (8 minutes).** Give out Handout 4. Student A has just moved to a new place (a city, a country, a job, a university hostel). Student B is a friend asking questions: *"How are you finding it? Are you used to the food yet?"* A answers: *"Not really, but I'm getting used to it. I used to ..."* Swap.
   - ICQs: *"Who has moved?"* (Student A, then B.)
2. **Discuss (7 minutes).** Groups discuss the situations: *"Which changes are easy to get used to? Which are difficult? Have you ever had to get used to something difficult?"*
3. **Report (3 minutes).** Groups share the most surprising answer.
4. Monitor and note language use.

### Stage 5: Feedback and wrap-up (7 minutes)

**Stage aim:** To give feedback and consolidate. **Interaction:** Whole class

1. Board sentences from Stage 4 (correct and incorrect). Students correct them.
2. Quick fire: say a situation; students respond with one of the three structures.
3. Set the homework.

### Stage 6: Homework

**Set at the end of the lesson.**

Write an email (180 words) to a friend about a big change in your life (a new school, job, home or country). Use *used to*, *be used to* and *get used to* at least twice each, in different tenses.

## Differentiation

**Support**

- Give weaker students the timeline and the three-column board.
- Focus on *used to* and *be used to* first, then add *get used to*.

**Stretch**

- Stronger students use *become accustomed to* (formal) and *take some getting used to*: *The cold takes some getting used to.*
- They use *get used to* in the present perfect and future perfect: *By next year, I'll have got used to it.*

## Assessment and success criteria

- 10 out of 12 or better on Handout 3.
- In the role-play, students use noun / -ing after *be / get used to*.
- Students use *get used to* for the process of adapting.

## Teacher's reflection

- Did the comparison with *look forward to* help?
- Did students use different tenses of *get used to*?

# Handout 1: From Colombo to Toronto

Name: ______________________________ Date: ______________

**Six months in Canada**

When I lived in Colombo, I used to wear shorts and sandals all year. Now I'm wearing three layers and boots! I'm still not used to the cold. Minus 15 °C is a shock for someone who used to complain when it was 25 °C.

At first, the food was a problem. I'm used to eating rice and curry every day, and here everything tastes bland. But I'm getting used to it, and I've found a Sri Lankan shop that sells curry leaves.

I used to take a tuk-tuk everywhere. Now I take the subway, and I've already got used to it; it's fast and clean. The hardest thing is being away from my family. I don't think I'll ever get used to that.
