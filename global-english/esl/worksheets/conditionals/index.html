First and Second Conditionals Worksheet (B1)

A printable conditionals worksheet for B1 learners: the first and second conditional, choosing between them, the comma rule, and giving advice with If I were you. Full answer key and teacher's notes.

  • CEFR B1
  • About 35 minutes
  • Printable
  • Answer key
  • First and Second Conditionals

About this worksheet

It goes with the Conditionals lesson plan but works on its own, in class or as homework.

Prints without the site's menus or advertisements.

First and Second Conditionals · Level B1 · About 35 minutes

Name: ______________________________ Date: ______________

Task 1. First conditional

Complete with the present simple or will / won't.

Example: If it rains (rain), we will stay (stay) at home.

  1. If you ________ (not hurry), you ________ (miss) the bus.
  2. I ________ (call) you if I ________ (finish) early.
  3. If she ________ (pass) the test, her parents ________ (be) very happy.
  4. We ________ (not go) to the beach if the weather ________ (be) bad.
  5. What ________ you ________ (do) if they ________ (say) no?

Task 2. Second conditional

Complete with the past simple or would / wouldn't.

Example: If I had (have) more time, I would learn (learn) the guitar.

  1. If I ________ (be) you, I ________ (talk) to the teacher.
  2. She ________ (travel) more if she ________ (not have) a small child.
  3. If we ________ (live) near the sea, we ________ (swim) every day.
  4. What ________ you ________ (say) if he ________ (ask) you?
  5. They ________ (not complain) if the food ________ (be) better.

Task 3. Which one?

Choose the first or the second conditional, and write the sentence. Ask yourself: is this a real possibility?

Example: (my bus is late most days) If the bus ________ late again, I ________ walk. → If the bus is late again, I will walk.

  1. (I have no money for a trip) If I ________ (have) the money, I ________ (go) to Japan.
  2. (there is a test next week) If I ________ (study) every evening, I ________ (pass) it.
  3. (I am not the head teacher) If I ________ (be) the head teacher, I ________ (change) the timetable.
  4. (rain is forecast for tomorrow) If it ________ (rain), the match ________ (be) cancelled.

Task 4. Commas

Write each sentence the other way round, and punctuate it correctly.

Example: If I see her, I'll tell her. → I'll tell her if I see her.

  1. If you need help, ask me. → ________________________
  2. I would buy a bicycle if I lived closer. → ________________________
  3. If we left now, we would arrive before dark. → ________________________
  4. She'll be angry if you forget again. → ________________________

Task 5. Your turn: give advice

Write advice for each problem using If I were you, I'd ... Then write one first conditional sentence about your own week.

  • A friend is always late for class. → ________________________
  • Your cousin wants to learn English quickly. → ________________________
  • Someone has lost their phone at school. → ________________________
  • About my week: ________________________

For the teacher: answer key

TaskAnswers
Task 11 don't hurry / will miss 2 will call / finish 3 passes / will be 4 won't go / is 5 will ... do / say
Task 21 were / would talk 2 would travel / didn't have 3 lived / would swim 4 would ... say / asked 5 wouldn't complain / were
Task 31 If I had the money, I would go to Japan. (unreal) 2 If I study every evening, I will pass it. (real) 3 If I were the head teacher, I would change the timetable. (unreal) 4 If it rains, the match will be cancelled. (real)
Task 41 Ask me if you need help. 2 If I lived closer, I would buy a bicycle. 3 We would arrive before dark if we left now. 4 If you forget again, she'll be angry. (Comma only when the if-clause comes first.)
Task 5Answers will vary. Check: If I were you, I'd + base verb; and the first conditional sentence has a present tense after if, never will.

Teacher's notes

  • Timing: Tasks 1 to 4 take about 25 minutes; Task 5 about 10, or set it as homework.
  • The one to watch: will after if. It is the most persistent mistake in the whole B1 syllabus, and it appears in Tasks 1, 3 and 5. One rule on the board beats twenty corrections.
  • If I were or if I was: were is the form expected in exams and in writing, and was is very common in speech. Teach were, and do not mark was wrong when a learner says it aloud.
  • Task 3 is the thinking task. Learners who can do Tasks 1 and 2 but not Task 3 have the forms without the meaning, which is exactly what to spend the next lesson on.
  • Extension: learners write three dilemmas of their own and swap them with a partner, who answers each with one conditional sentence.
